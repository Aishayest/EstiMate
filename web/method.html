How it works, and how we checked it.

The goal was not a record score. It was an honest test: the tool learns from older tasks and is graded once, at the very end, on newer tasks it has never seen.

Run everything yourself python -m src.pipeline ~10 min · the same numbers every time

01 — Six steps

  1. 01 → Real tasks 9,468 tasks with story points from 4 open-source teams.
  2. 02 → Old vs new Learn from the oldest 60%, set the range on the next 20%, grade on the newest 20%.
  3. 03 → Read the words Turn the text into numbers: which words appear, and how rare they are (TF-IDF).
  4. 04 → Guess a size A simple linear model (Ridge) links those words to story points.
  5. 05 → Measure the mistakes See how far off it was on tasks it didn't learn from. That sets the range width.
  6. 06 ■ Final grade, once Check the newest tasks at the very end. No changes after that.

02 — Where the range comes from

Look at how wrong the tool was on tasks it hadn't seen. Make the range just wide enough to cover 9 out of 10 of those mistakes.

This is called conformal prediction. It comes with a real guarantee, but only while new tasks resemble the ones used to set the range. Section 04 shows a team where they didn't.

The math, for the curious
# how wrong was it on n tasks it didn't learn from?
r_i = |real_i − guess_i|

# margin that covers a share 1 − α of them
q   = r_(k),   k = ⌈(n + 1)(1 − α)⌉

# range for a new task
[ max(1, guess − q),  guess + q ]

# story points are whole numbers: round inward,
# the share it catches stays the same
[ ⌈low⌉, ⌊high⌋ ]

04 — When the promise breaks — typical task size, , earlier → later

The team started sizing tasks smaller. The tool didn't know.

Ranges set on older tasks sat too high for new ones.

The method did what it promises. Its one assumption, that the future looks like the past, did not hold for this team. That is why the site warns about it.

05 — Run it yourself

One command downloads the data, trains and checks everything, draws the charts and builds the files this site loads.

Open the code ↗ 
$ git clone https://github.com/Aishayest/EstiMate
$ cd EstiMate && python -m venv .venv
$ .venv/bin/pip install -r requirements.txt
$ .venv/bin/python -m src.pipeline
